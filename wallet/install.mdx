# Installing the Wallet

## From the Chrome Web Store

<Note>
The public Chrome Web Store listing may not be live yet. If a search for **Ansem** turns up nothing, the extension has not been published to your region yet; check the official site for the current install link.
</Note>

<Steps>

### Install the extension

Search for **Ansem** in the Chrome Web Store and press *Add to Chrome*. Works on Chrome, Brave, Edge, and other Chromium browsers.

### Create your wallet

Open the extension and choose **Create new wallet**. Set a password: it encrypts your keys on this device.

### Back up your seed phrase

Write down the recovery phrase and store it offline. This is the only way to recover your wallet. The extension reminds you until you confirm the backup.

### Done

Your wallet now has an ansemchain address (starts with `ansem1`) and a Solana address, both derived from the same phrase.

</Steps>

## Importing an existing wallet

Choose **Import** instead, then enter a seed phrase or a private key. Hardware wallets and watch-only (address only) imports are supported too.

## Multiple wallets

You can hold any number of wallets in one extension and switch between them from the wallets screen.
