# Transfer Tokens

The `ansem token transfer` command sends CW20 tokens from your account to another address.

## Usage

```bash wrap
ansem token transfer <contract> <recipient> <amount> --from <key>
```

### Arguments

| Argument | Description |
|----------|-------------|
| `contract` | Token contract address |
| `recipient` | Destination address |
| `amount` | Amount to send (in smallest unit) |

### Flags

| Flag | Description | Required |
|------|-------------|----------|
| `--from` | Your signing key | Yes |
| `--dry-run` | Simulate only | No |

## Examples

### Basic Transfer

```bash wrap
ansem token transfer ansem1tokencontract... ansem1recipient... 1000000 --from mykey
```

### Transfer All Tokens

First check your balance:
```bash wrap
ansem token balance ansem1tokencontract... --key mykey
# Balance: 5000000
```

Then transfer:
```bash wrap
ansem token transfer ansem1tokencontract... ansem1recipient... 5000000 --from mykey
```

### Dry Run

```bash wrap
ansem token transfer ansem1tokencontract... ansem1recipient... 1000000 --from mykey --dry-run
```

## Verify Transfer

Check balances after transfer:

```bash wrap
# Your balance
ansem token balance ansem1tokencontract... --key mykey

# Recipient balance
ansem token balance ansem1tokencontract... ansem1recipient...
```

## Amount Calculation

Amount is in the token's smallest unit. For 6 decimals:

| Display | Amount (base) |
|---------|---------------|
| 1 MTK | 1,000,000 |
| 0.5 MTK | 500,000 |
| 100 MTK | 100,000,000 |

Example: Send 10 tokens:
```bash wrap
ansem token transfer ansem1contract... ansem1recipient... 10000000 --from mykey
#                                                  ^ 10 * 10^6
```

## Batch Transfers

### Sequential

```bash wrap
ansem token transfer ansem1contract... ansem1addr1... 1000000 --from mykey
ansem token transfer ansem1contract... ansem1addr2... 2000000 --from mykey
ansem token transfer ansem1contract... ansem1addr3... 3000000 --from mykey
```

### Script

```bash wrap
#!/bin/bash
CONTRACT="ansem1tokencontract..."
KEY="mykey"

# Recipients and amounts
declare -A TRANSFERS=(
  ["ansem1addr1..."]="1000000"
  ["ansem1addr2..."]="2000000"
  ["ansem1addr3..."]="3000000"
)

for addr in "${!TRANSFERS[@]}"; do
  amount=${TRANSFERS[$addr]}
  echo "Sending $amount to $addr..."
  ansem token transfer $CONTRACT $addr $amount --from $KEY
  sleep 1
done
```

## Error Handling

| Error | Meaning | Solution |
|-------|---------|----------|
| "insufficient token balance" | Not enough tokens | Check balance first |
| "invalid address" | Bad recipient format | Verify address format (ansem1...) |
| "contract not found" | Wrong contract address | Verify contract exists |

### Check Balance Before Transfer

```bash wrap
# Check your balance
BALANCE=$(ansem token balance ansem1contract... --key mykey --output json | jq -r '.balance')

# Compare with amount
if [ "$BALANCE" -lt "1000000" ]; then
  echo "Insufficient balance: $BALANCE"
  exit 1
fi
```

## Under the Hood

`ansem token transfer` executes a `MsgExecuteContract`:

```json wrap
{
  "contract": "ansem1tokencontract...",
  "msg": {
    "transfer": {
      "recipient": "ansem1recipient...",
      "amount": "1000000"
    }
  },
  "funds": []
}
```

## Transfer vs Send

CW20 has two transfer methods:

| Method | Use Case |
|--------|----------|
| `transfer` | Send to regular address |
| `send` | Send to contract with callback |

The `ansem token transfer` command uses `transfer`. For contract interactions, use `ansem program execute`.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Insufficient balance">
    Check your current balance:
    ```bash
    ansem token balance ansem1contract... --key mykey
    ```
    You can only transfer what you have.
  </Accordion>

  <Accordion title="Invalid recipient">
    Ensure the address:
    - Starts with `ansem1`
    - Is the correct length
    - Has valid checksum
  </Accordion>

  <Accordion title="Transaction timeout">
    The node may be slow. Check status:
    ```bash
    curl https://rpc.ansemchain.fun/status | jq '.result.sync_info'
    ```
    Retry the transfer if needed.
  </Accordion>
</AccordionGroup>
