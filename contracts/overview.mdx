# Smart Contracts

ansemchain supports [CosmWasm](https://cosmwasm.com) smart contracts - Rust-based programs that run on the blockchain, similar to Solana programs.

## Contract Lifecycle

```
┌─────────────┐     ┌───────────────┐     ┌─────────────┐     ┌─────────────┐
│  Scaffold   │────▶│    Build      │────▶│   Deploy    │────▶│  Interact   │
│  (ansem init) │     │(ansem program   │     │(ansem program │     │(execute/    │
│             │     │    build)     │     │   deploy)   │     │   query)    │
└─────────────┘     └───────────────┘     └─────────────┘     └─────────────┘
```

1. **Scaffold** - Create project structure with `ansem init`
2. **Build** - Compile Rust to optimized Wasm with `ansem program build`
3. **Deploy** - Upload and instantiate with `ansem program deploy`
4. **Interact** - Execute methods and query state

## Commands

| Command | Description |
|---------|-------------|
| `ansem init` | Scaffold new contract project |
| `ansem program build` | Compile to optimized Wasm |
| `ansem program deploy` | Upload and instantiate contract |
| `ansem program execute` | Call contract method |
| `ansem program query` | Read contract state |
| `ansem program list` | List deployed contracts |
| `ansem program info` | Contract details |
| `ansem localnet` | Local development network |

## Quick Start

### 1. Start Local Network

```bash wrap
ansem localnet start
```

### 2. Scaffold Project

```bash wrap
ansem init my-contract
cd my-contract
```

### 3. Build Contract

```bash wrap
ansem program build
```

### 4. Deploy

```bash wrap
ansem program deploy artifacts/my_contract.wasm --from alice --label "My Contract"
```

### 5. Interact

```bash wrap
# Query state
ansem program query ansem1contract... '{"get_count":{}}'

# Execute method
ansem program execute ansem1contract... '{"increment":{}}' --from alice
```

## Project Structure

`ansem init` creates:

```
my-contract/
├── Cargo.toml           # Rust dependencies
├── src/
│   ├── lib.rs          # Contract entry point
│   ├── contract.rs     # Main logic
│   ├── msg.rs          # Message types
│   ├── state.rs        # State storage
│   └── error.rs        # Custom errors
├── .gitignore
└── README.md
```

### Key Files

| File | Purpose |
|------|---------|
| `lib.rs` | Exports contract entry points |
| `contract.rs` | `instantiate`, `execute`, `query` functions |
| `msg.rs` | `InstantiateMsg`, `ExecuteMsg`, `QueryMsg` |
| `state.rs` | Storage using `cw-storage-plus` |
| `error.rs` | Custom error types |

## Contract Entry Points

Every CosmWasm contract has three entry points:

```rust wrap
// Called once when contract is created
pub fn instantiate(
    deps: DepsMut,
    env: Env,
    info: MessageInfo,
    msg: InstantiateMsg,
) -> Result<Response, ContractError>

// Called to modify state
pub fn execute(
    deps: DepsMut,
    env: Env,
    info: MessageInfo,
    msg: ExecuteMsg,
) -> Result<Response, ContractError>

// Called to read state (no state changes)
pub fn query(
    deps: Deps,
    env: Env,
    msg: QueryMsg,
) -> StdResult<Binary>
```

## Message Types

### InstantiateMsg

Configuration when creating the contract:

```rust wrap
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub struct InstantiateMsg {
    pub count: i32,
    pub owner: String,
}
```

### ExecuteMsg

Actions that modify state:

```rust wrap
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub enum ExecuteMsg {
    Increment {},
    Decrement {},
    Reset { count: i32 },
}
```

### QueryMsg

Read-only requests:

```rust wrap
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub enum QueryMsg {
    GetCount {},
    GetOwner {},
}
```

## Gas & Fees

CosmWasm operations use more gas than standard transactions:

| Operation | Typical Gas |
|-----------|-------------|
| Store (upload) | 1,000,000 - 5,000,000 |
| Instantiate | 200,000 - 500,000 |
| Execute | 100,000 - 300,000 |
| Query | Free (no tx) |

The CLI automatically estimates gas with a 1.3x buffer.

| CW4 | Groups | Membership management |
