# Executing Contracts

The `ansem program execute` command calls contract methods that modify state (like a transaction).

## Usage

```bash wrap
ansem program execute <contract> <message> --from <key> [options]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `contract` | Contract address |
| `message` | JSON message or @file.json |

## Basic Execution

```bash wrap
ansem program execute ansem1contract... '{"increment":{}}' --from alice
```

Output:
```
Transaction Successful!

Contract: ansem1contract...
Method:   increment
TxHash:   ABC123DEF456...
Gas Used: 115678
Block:    12345
```

## Message Formats

### Inline JSON

```bash wrap
ansem program execute ansem1contract... '{"increment":{}}' --from alice
```

### With Parameters

```bash wrap
ansem program execute ansem1contract... '{"reset":{"count":100}}' --from alice
```

### From File

```bash wrap
# Create message file
echo '{"transfer":{"recipient":"ansem1recipient...","amount":"1000"}}' > msg.json

# Execute from file
ansem program execute ansem1contract... @msg.json --from alice
```

## Options

| Flag | Description | Default |
|------|-------------|---------|
| `--from` | Signing key | Required |
| `--funds` | Send funds with execution | None |
| `--dry-run` | Simulate only | false |
| `--gas-buffer` | Gas multiplier | 1.3 |

## Examples

### Transfer Tokens (CW20)

```bash wrap
ansem program execute ansem1tokencontract... \
  '{"transfer":{"recipient":"ansem1bob...","amount":"1000000"}}' \
  --from alice
```

### Send with Funds

Some contracts require funds with execution:

```bash wrap
ansem program execute ansem1escrowcontract... \
  '{"deposit":{}}' \
  --from alice \
  --funds 1000000uchanse
```

### Batch Operations

```bash wrap
ansem program execute ansem1contract... \
  '{"batch":{"operations":[{"increment":{}},{"increment":{}},{"increment":{}}]}}' \
  --from alice
```

## Dry Run

Simulate without broadcasting:

```bash wrap
ansem program execute ansem1contract... '{"increment":{}}' --from alice --dry-run
```

Output:
```

Estimated fee: 1,500 uchanse

Execute Details:
  Contract: ansem1contract...
  Message: {"increment":{}}
  Funds: 0
```

## Authorization

Execute methods may have authorization requirements:

### Public Methods

Anyone can call:

```rust wrap
ExecuteMsg::Increment {} => { /* anyone */ }
```

### Owner-Only Methods

```rust wrap
ExecuteMsg::Reset { count } => {
    if info.sender != OWNER.load(deps.storage)? {
        return Err(ContractError::Unauthorized {});
    }
    // ...
}
```

Error when unauthorized:
```
Error: permission denied: only the contract owner can reset
```

## Error Handling

The CLI provides user-friendly errors:

| Chain Error | CLI Message |
|-------------|-------------|
| `unauthorized` | Permission denied: only the contract owner can... |
| `insufficient funds` | Insufficient balance to complete... |
| `out of gas` | Transaction requires more gas. Try increasing --gas |

## Complex JSON

For complex messages, use a file:

```bash wrap
# Create complex message
cat > msg.json << 'EOF'
{
  "create_proposal": {
    "title": "Upgrade Protocol",
    "description": "This proposal upgrades the protocol to v2",
    "msgs": [
      {
        "wasm": {
          "execute": {
            "contract_addr": "ansem1other...",
            "msg": {"upgrade": {"version": "2.0.0"}},
            "funds": []
          }
        }
      }
    ]
  }
}
EOF

# Execute
ansem program execute ansem1governance... @msg.json --from alice
```

## Scripting

### Check Result

```bash wrap
# Execute and capture tx hash
RESULT=$(ansem program execute ansem1contract... '{"increment":{}}' --from alice 2>&1)
TXHASH=$(echo "$RESULT" | grep "TxHash:" | awk '{print $2}')

echo "Transaction: $TXHASH"
```

### Retry on Failure

```bash wrap
#!/bin/bash
MAX_RETRIES=3
RETRY=0

while [ $RETRY -lt $MAX_RETRIES ]; do
  if ansem program execute ansem1contract... '{"increment":{}}' --from alice; then
    echo "Success!"
    exit 0
  fi
  RETRY=$((RETRY + 1))
  echo "Retry $RETRY/$MAX_RETRIES..."
  sleep 2
done

echo "Failed after $MAX_RETRIES retries"
exit 1
```
