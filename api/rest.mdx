# REST API

The REST API provides HTTP access to chain state and CosmWasm queries.

## Endpoint

```
https://rest.ansemchain.fun
```

## Swagger Documentation

Interactive API docs available at:

```
https://rest.ansemchain.fun/swagger/
```

### Query Contract State (Smart)

The query message must be base64 encoded:

```bash wrap
# Base64 encode the query
QUERY=$(echo -n '{"get_count":{}}' | base64)
# eyJnZXRfY291bnQiOnt9fQ==

curl "https://rest.ansemchain.fun/cosmwasm/wasm/v1/contract/ansem1contract.../smart/$QUERY"
```

<Accordion title="Response">
```json wrap
{
  "data": {"count": 42}
}
```
</Accordion>

### Query Contract State (Raw)

Query raw storage by key:

```bash wrap
KEY=$(echo -n "config" | xxd -p)
curl "https://rest.ansemchain.fun/cosmwasm/wasm/v1/contract/ansem1contract.../raw/$KEY"
```

## Transactions

### Get Transaction by Hash

```bash wrap
curl https://rest.ansemchain.fun/cosmos/tx/v1beta1/txs/ABC123...
```

<Accordion title="Response">
```json wrap
{
  "tx": {
    "body": {
      "messages": [...],
      "memo": ""
    },
    "auth_info": {...},
    "signatures": [...]
  },
  "tx_response": {
    "height": "12345",
    "txhash": "ABC123...",
    "code": 0,
    "gas_wanted": "200000",
    "gas_used": "150000",
    "events": [...]
  }
}
```
</Accordion>

### Search Transactions

```bash wrap
# By sender
curl "https://rest.ansemchain.fun/cosmos/tx/v1beta1/txs?events=message.sender='ansem1sender...'"

# By recipient
curl "https://rest.ansemchain.fun/cosmos/tx/v1beta1/txs?events=transfer.recipient='ansem1recipient...'"

# By height
curl "https://rest.ansemchain.fun/cosmos/tx/v1beta1/txs?events=tx.height=12345"
```

### Simulate Transaction

```bash wrap
curl -X POST https://rest.ansemchain.fun/cosmos/tx/v1beta1/simulate \
  -H "Content-Type: application/json" \
  -d '{
    "tx_bytes": "base64-encoded-tx",
    "mode": "BROADCAST_MODE_SYNC"
  }'
```

### Broadcast Transaction

```bash wrap
curl -X POST https://rest.ansemchain.fun/cosmos/tx/v1beta1/txs \
  -H "Content-Type: application/json" \
  -d '{
    "tx_bytes": "base64-encoded-signed-tx",
    "mode": "BROADCAST_MODE_SYNC"
  }'
```

Modes:
- `BROADCAST_MODE_SYNC` - Wait for CheckTx
- `BROADCAST_MODE_ASYNC` - Return immediately
- `BROADCAST_MODE_BLOCK` - Wait for block (deprecated)

## Pagination

Most list endpoints support pagination:

```bash wrap
# First page
curl "https://rest.ansemchain.fun/cosmos/bank/v1beta1/balances/ansem1...?pagination.limit=10"

# Next page (use next_key from previous response)
curl "https://rest.ansemchain.fun/cosmos/bank/v1beta1/balances/ansem1...?pagination.key=ABC123&pagination.limit=10"

# Get total count
curl "https://rest.ansemchain.fun/cosmos/bank/v1beta1/balances/ansem1...?pagination.count_total=true"
```

## Error Handling

### Error Response

```json wrap
{
  "code": 5,
  "message": "rpc error: code = NotFound desc = account ansem1invalid... not found",
  "details": []
}
```

### Common Error Codes

| Code | Description |
|------|-------------|
| 2 | Unknown error |
| 3 | Invalid argument |
| 5 | Not found |
| 11 | Out of range |
