# API Endpoints

A reference list of the public ansemchain endpoints. This page lists what is
available. Detailed usage guides are not published yet.

## Base URLs

| Endpoint | URL | What it is |
|----------|-----|------------|
| Chain RPC (CometBFT) | `https://rpc.ansemchain.fun` | Consensus RPC for blocks, transactions, and broadcasting |
| REST / LCD | `https://rest.ansemchain.fun` | Cosmos SDK REST interface for chain state |
| Launchpad API | `https://api.ansemchain.fun` | Pre-indexed data for launchpad tokens, trades, and prices |

gRPC is not exposed publicly. It runs on port 9090 of a node you run yourself.

For local development the same interfaces run at `http://localhost:26657` (RPC),
`http://localhost:1317` (REST), and `localhost:9090` (gRPC).

## REST / LCD route families

Base: `https://rest.ansemchain.fun`

| Route | What it is |
|-------|------------|
| `/cosmos/base/tendermint/v1beta1/node_info` | Node and network info |
| `/cosmos/base/tendermint/v1beta1/blocks/latest` | Latest block |
| `/cosmos/base/tendermint/v1beta1/blocks/{height}` | Block at a height |
| `/cosmos/tx/v1beta1/txs/{hash}` | Transaction by hash |
| `/cosmos/auth/v1beta1/accounts/{address}` | Account details |
| `/cosmos/bank/v1beta1/balances/{address}` | Account balances |
| `/cosmos/bank/v1beta1/supply` | Total supply |
| `/cosmos/bank/v1beta1/denoms_metadata` | Token metadata |
| `/cosmos/staking/v1beta1/validators` | Validator set |
| `/cosmos/staking/v1beta1/pool` | Staking pool totals |
| `/cosmos/gov/v1/params/voting` | Governance voting parameters |
| `/cosmwasm/wasm/v1/contract/{address}/smart/{query}` | Smart contract query |

## Launchpad API routes

Base: `https://api.ansemchain.fun`

| Route | What it is |
|-------|------------|
| `GET /api/health` | Service health check |
| `GET /api/tokens` | List launchpad tokens |
| `GET /api/tokens/:address` | Single token detail |
| `GET /api/candles/:address` | OHLCV candlestick data for a token |
| `GET /api/trades/recent` | Recent trades |
| `GET /api/sse/feed` | Real-time trade feed (Server-Sent Events) |
| `GET /api/wallet/balance` | Wallet native balance |
| `GET /api/wallet/tokens` | Wallet token holdings |
| `GET /api/wallet/prices` | Prices for a wallet's tokens |
| `GET /api/wallet/transactions` | Wallet transaction history |
| `POST /api/wallet/broadcast` | Broadcast a signed transaction |
