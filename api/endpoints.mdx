# API Overview

ansemchain exposes three API interfaces for programmatic access.

## Available APIs

| API | Port | Protocol | Best For |
|-----|------|----------|----------|
| [Chain RPC](/api/rpc) | 26657 | HTTP/WebSocket | Transactions, blocks, consensus |
| [REST API](/api/rest) | 1317 | HTTP | Browser apps, simple queries |
| [gRPC](/api/grpc) | 9090 | HTTP/2 | High-performance, typed clients |

## Endpoints by Network

### Public (live chain)

```
RPC:  https://rpc.ansemchain.fun
REST: https://rest.ansemchain.fun
```

gRPC is not exposed publicly; it is available on a node you run yourself (port 9090).

### Local development

```
RPC:  http://localhost:26657
REST: http://localhost:1317
gRPC: localhost:9090
```

## Quick Examples

### Check Node Status

<CodeGroup>
```bash curl
curl https://rpc.ansemchain.fun/status
```

```bash REST
curl https://rest.ansemchain.fun/cosmos/base/tendermint/v1beta1/node_info
```

```bash grpcurl
grpcurl -plaintext localhost:9090 cosmos.base.tendermint.v1beta1.Service/GetNodeInfo
```
</CodeGroup>

### Query Account Balance

<CodeGroup>
```bash curl (RPC)
curl 'https://rpc.ansemchain.fun/abci_query?path="/cosmos.bank.v1beta1.Query/Balance"&data=...'
```

```bash REST
curl https://rest.ansemchain.fun/cosmos/bank/v1beta1/balances/ansem1address...
```

```bash grpcurl
grpcurl -plaintext -d '{"address":"ansem1address..."}' \
  localhost:9090 cosmos.bank.v1beta1.Query/AllBalances
```
</CodeGroup>

### Query Smart Contract

<CodeGroup>
```bash ansem CLI
ansem program query ansem1contract... '{"get_count":{}}'
```

```bash REST
curl -X GET "https://rest.ansemchain.fun/cosmwasm/wasm/v1/contract/ansem1contract.../smart/eyJnZXRfY291bnQiOnt9fQ=="
```
</CodeGroup>

Note: The REST query data is base64-encoded JSON.

## Choosing an API

### Use Chain RPC when:

- Broadcasting transactions
- Subscribing to events (WebSocket)
- Querying blocks and transactions
- Checking consensus state

### Use REST API when:

- Building browser applications
- Simple one-off queries
- Human-readable responses
- Quick prototyping

### Use gRPC when:

- Building production services
- Need strongly-typed clients
- High-performance requirements
- Streaming responses

## Authentication

### Public Endpoints

All read operations are public and don't require authentication:

```bash wrap
# No auth needed
curl https://rest.ansemchain.fun/cosmos/bank/v1beta1/balances/ansem1...
```

### Transaction Signing

Transactions must be signed client-side:

```bash wrap
# Sign with ansem CLI
ansem tx send ansem1recipient... 1000uchanse --from alice

# Or sign programmatically and broadcast via API
curl -X POST https://rpc.ansemchain.fun/broadcast_tx_sync \
  -d '{"tx": "base64-encoded-signed-tx"}'
```

### Localnet

## Common Patterns

### Health Check

```bash wrap
# Simple health check
curl -f https://rpc.ansemchain.fun/health && echo "Healthy"
```

### Wait for Block

```bash wrap
#!/bin/bash
TARGET_BLOCK=$1
while true; do
  CURRENT=$(curl -s https://rpc.ansemchain.fun/status | jq -r '.result.sync_info.latest_block_height')
  if [ "$CURRENT" -ge "$TARGET_BLOCK" ]; then
    echo "Reached block $CURRENT"
    break
  fi
  sleep 1
done
```

### Poll for Transaction

```bash wrap
#!/bin/bash
TX_HASH=$1
while true; do
  RESULT=$(curl -s "https://rpc.ansemchain.fun/tx?hash=0x$TX_HASH")
  if echo "$RESULT" | jq -e '.result' > /dev/null 2>&1; then
    echo "Transaction confirmed"
    echo "$RESULT" | jq '.result'
    break
  fi
  sleep 1
done
```

## WebSocket Subscriptions

Subscribe to real-time events via Chain RPC:

```javascript wrap
const ws = new WebSocket('wss://rpc.ansemchain.fun/websocket');

ws.onopen = () => {
  // Subscribe to new blocks
  ws.send(JSON.stringify({
    jsonrpc: '2.0',
    method: 'subscribe',
    params: ["tm.event='NewBlock'"],
    id: 1
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('New block:', data.result.data.value.block.header.height);
};
```

## Error Handling

### HTTP Status Codes

| Code | Meaning |
|------|---------|
| 200 | Success |
| 400 | Bad request (invalid parameters) |
| 404 | Resource not found |
| 500 | Internal server error |

### Error Response Format

```json wrap
{
  "code": 5,
  "message": "account ansem1invalid... not found",
  "details": []
}
```
